Про мене

Студентка НУ «Львівська політехніка», яка спеціалізується на кібербезпеці та захисті інформації. Захоплююсь аналізом вразливостей, безпекою вебсистем та криптографічним захистом даних.

Навички

  • Мови програмування: Python, C#
  • Вебтехнології: HTML5, CSS3, JavaScript, React
  • Кібербезпека: Аналіз вразливостей, Мережева безпека, Криптографія
  • Інструменти розробки: Git, GitHub, VS Code

Досвід та проєкти

Практичні лабораторні роботи у НУ «Львівська політехніка»

Виконання практичних завдань із захисту інформації, налаштування безпеки мереж, аналізу коду на вразливості та створення вебзастосунків із дотриманням принципів безпечної розробки.

Розробка безпечного веб-інтерфейсу (CV)

Створення семантичного вебдокумента та його декомпозиція на компоненти React із використанням системи контролю версій Git.
